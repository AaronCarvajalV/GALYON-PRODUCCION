# GALYON — Preparación visual v5.2.1

**Sitio de prueba:** v5.2.1. No se ha hecho ningún despliegue en Netlify.

## Cambio en los carruseles

- Antes: 3.500 ms; ahora: **2.000 ms** entre cambios automáticos, exclusivamente en cada modal abierto.
- Se mantienen el avance táctil/manual, la pausa al colocar el cursor y el respeto a preferencias de movimiento reducido.
- La velocidad de transición visual CSS no se ha modificado; este valor es la **frecuencia** de cambio.

## Prioridades para la siguiente integración

1. Conseguir y verificar **imágenes independientes de arroz** (planta entera, hoja, vainas/tallos, raíces, espigas).
2. Completar **banano y caña de azúcar** por órgano; evitar reutilizar la misma imagen de la plantación.
3. Hacer fotos propias de portada para **tomate, ají, cítricos, mango, chirimoya, papaya, ornamentales y aromáticas**.
4. Incorporar síntomas específicos solo cuando exista referencia visual suficientemente fiel; **no usar recortes diminutos de infografías**.
5. Probar el resultado comercial por problema **con una línea/propuesta por validar**, sin seleccionar BACT automáticamente para cualquier síntoma ambiguo.

## Evidencia y resultados esperados

El INIAP distingue moniliasis, mazorca negra y escoba de bruja como problemas importantes del cacao y describe el uso de manejo integrado y agentes de control biológico. Las propiedades evaluadas de ciertas cepas de *Trichoderma* no implican eficacia demostrada de cualquier presentación GALYON. Para indicar reducción concreta de incidencia o aumentos de rendimiento se necesitarían ensayos de la formulación comercial.
